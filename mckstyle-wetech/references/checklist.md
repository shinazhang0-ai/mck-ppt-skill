# checklist.md — 质量检查清单

生成完成后必须逐项过检。P0 全部通过才能交付。

---

## P0 级（不通过 = 直接返工，不能交付）

### 内容质量
- [ ] **所有 slide 标题都是 Action Title**（完整论点句，带数据或结论，不是话题标签）
- [ ] **执行摘要页存在**（deck 第 2 页），且 30 秒内能让受众理解全部结论
- [ ] **没有孤立数据**（每个数字都有对应的 so what 解释）
- [ ] **结论先行**（核心观点在每页标题就能看到，不藏在正文里）
- [ ] **建议/结论页存在**，且包含可量化的预期影响

### 视觉
- [ ] **颜色不超过 2 主色 + 1 强调色**（无渐变背景、无装饰图形、无 emoji）
- [ ] **内容不溢出 100vh**（每页 slide 完整显示，无滚动条）
- [ ] **字体为无衬线体**（Inter 或同等），数字清晰可读（tabular nums）
- [ ] **每页信息密度正常**：正文不超过 25 字/行，支撑点不超过 3 个

### 技术
- [ ] **HTML 单文件可独立运行**（无外部依赖文件，CDN 链接有效）
- [ ] **翻页功能正常**（← → 键、底部点击均可翻页）
- [ ] **图表可读**（SVG 数值标签存在，轴标签存在，有图例）

---

## P1 级（发现即修复，不影响交付但必须在用户看到前处理）

### 内容
- [ ] **MECE 检查**：并列信息点无重叠、无明显遗漏
- [ ] **数据有来源注明**（右下角 source 标注）
- [ ] **建议有优先级排序**（不是等权并列）
- [ ] **时间线有具体季度/年份**（不是模糊的"短期/中期/长期"）

### 视觉
- [ ] **表格有视觉重点**（关键数字用颜色/加粗区分，不是所有数字一视同仁）
- [ ] **柱状图/折线图有基准线**（行业均值、历史数据、或目标值）
- [ ] **章节分隔页存在**（超过 8 页的 deck 必须有）
- [ ] **封面信息完整**（标题、副标题、日期、准备方）

---

## P2 级（有时间就修，没时间可以放过）

- [ ] 过渡动画是否平滑（fade 或 slide，不要 bounce）
- [ ] 打印/PDF 导出是否正常（可选，非必须）
- [ ] 数字格式统一（万/亿 or M/B 只用一套，不混用）
- [ ] 中英文标点混用（全角/半角统一）

---

## 最常见 P0 失误速查（历史踩坑）

| 失误 | 症状 | 修复 |
|------|------|------|
| 标题是话题而非论点 | `竞争分析` | 改为 `竞争格局前3家占72%，尾部加速出清` |
| 数据无 so what | 只写 `转化率 3.2%` | 加 `→ 低于行业均值 1.8pp，每月损失约 240 万` |
| 颜色过多 | 超过 3 种颜色 | 只保留主色、白色、1 种强调色 |
| 信息过载 | 一页 5+ 个点 | 拆成两页，每页 ≤ 3 个支撑点 |
| 内容溢出 | 出现滚动条 | 减少内容或调小字号（最小 `0.85vw`） |
| 结论藏在最后 | 受众要读完才知道结论 | 把结论移到 Action Title |
| 图表无基准 | 单一绝对值 | 加行业均值线或对比期数据 |
| 建议无量化影响 | `建议加强数字化建设` | `建议投入 800 万预算数字化渠道，预期 18 个月 ROI 达 2.8×` |
